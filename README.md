Простой браузер без специальных разрешений для запуска Web версии Max.

Перед запуском убедитесь что вышли из всех сессий на мобильных устройствах.

Данный браузер не имеет доступа к камере и файлам, так что его возможности ограничены, но он отлично подходит для тех, кто не отправляет файлы и не хочет разбираться с разрешениями.

В этом его и суть.

Также он не отправляет трафик если вы случайно зашли с VPN чтобы не спалить ваш сервер.
